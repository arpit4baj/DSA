
# 📊 Complexity Cheat Sheet

| Data Structure / Algorithm |    Average |
| -------------------------- | ---------: |
| Array Access               |       O(1) |
| Array Search               |       O(n) |
| HashMap Search             |       O(1) |
| HashSet Search             |       O(1) |
| Binary Search              |   O(log n) |
| Merge Sort                 | O(n log n) |
| Quick Sort                 | O(n log n) |
| Tree Search                |  O(log n)* |
| Heap Insert                |   O(log n) |
| Heap Delete                |   O(log n) |

* Depends on the structure of the tree.
